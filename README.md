## 📌 Overview

This repository contains my personal developer portfolio, designed and developed to showcase my technical journey, software development skills, projects, and experiences as a Computer Science and Engineering student.

The portfolio is built as an interactive, modern, single-page web application with a futuristic dark visual theme, smooth transitions, animated backgrounds, and immersive UI elements. Rather than being a conventional static portfolio, it focuses on creating an engaging browsing experience through carefully designed sections, interactive components, motion effects, and dynamic content presentation.

The website introduces me, my technical interests, and my aspirations in software engineering while providing a structured overview of the technologies I work with and the projects I have developed. Each project is presented with its description, technology stack, key highlights, and GitHub repository link, allowing visitors to explore my actual development work.

The portfolio also includes dedicated sections for my technical skills, education, hackathon participation, achievements, and contact information. Its content is maintained through modular data files, making it easier to update personal details, add new projects, modify skills, and include future experiences without changing the overall application structure.

A major focus of this project is the combination of frontend engineering and visual storytelling. It incorporates reusable React components, animated interactions, smooth scrolling, responsive layouts, and custom background effects to create a consistent experience across desktop, tablet, and mobile devices.

**The primary goal of this portfolio is to present my work, demonstrate my technical capabilities, document my continuous learning journey, and provide recruiters, developers, and collaborators with a central place to explore my projects and connect with me.**

## ✨ Key Features

- **Interactive Hero Section:** Animated introduction, dynamic role presentation, call-to-action buttons, and developer-themed terminal interface.
- **About Me:** Detailed introduction covering my background, technical interests, learning mindset, and career aspirations.
- **Technical Skills:** Categorized display of programming languages, frontend technologies, backend technologies, databases, and developer tools.
- **Projects Showcase:** Interactive project presentation with descriptions, technology tags, key highlights, GitHub links, and conditional live-demo links.
- **Hackathons & Experience:** Timeline-based presentation of hackathon participation and other technical experiences with certificate access.
- **Education:** Academic background, coursework, and areas of technical focus.
- **Achievements:** Dedicated section for verified achievements, awards, and certifications.
- **Contact Section:** Contact information and email interaction for professional communication.
- **Animated Backgrounds:** Custom particle effects, dynamic visual elements, and interactive background animations.
- **Smooth Scrolling:** Enhanced navigation experience using Lenis and scroll-based interactions.
- **Responsive Design:** Optimized layouts for desktops, tablets, and mobile devices.
- **Reusable Architecture:** Modular components and data-driven sections for maintainability and scalability.

## ⚙️ Getting Started

### Prerequisites
- Node.js 18 or higher
- npm
- Git

### Installation

```bash
git clone https://github.com/tejamurthycng-arch/Portfolio.git

cd Portfolio

npm install

npm run dev
```

### Production Build

```bash
npm run build
npm run preview
```
