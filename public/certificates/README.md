# Certificates Directory
Place your hackathon and achievement PDF certificates here!

For example:
- `smart-city-hackathon.pdf`
- `ai-workshop-cert.pdf`

Once placed here, update `src/data/hackathons.ts` or `src/data/achievements.ts` with the file path (e.g. `/certificates/smart-city-hackathon.pdf`), and the verified certificate viewer button will appear on the card automatically!
